# Sushi Store

Uma experiência moderna de e-commerce para pedidos de sushi, com interface elegante, navegação fluida e fluxo de compra pensado para mobile e desktop.

Link: [sushi-store-xi.vercel.app](https://sushi-store-xi.vercel.app/)

## ✨ Destaques

- Catálogo visual de produtos com categorias
- Carrinho de compras com quantidade e resumo do pedido
- Fluxo de checkout com etapas organizadas
- Tema claro e escuro
- Layout responsivo e moderno
- Interface inspirada em alimentos premium e delivery digital

## 🛠️ Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- shadcn/ui
- Sonner

## 📦 Sobre o projeto

Este projeto foi desenvolvido para simular uma loja de sushi com foco em experiência de usuário, estética premium e usabilidade no processo de compra. A ideia foi criar um storefront com visual limpo, funcional e agradável, destacando os itens do cardápio e tornando o pedido rápido e intuitivo.
